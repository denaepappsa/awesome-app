每天采集一次（无需导出入口）

  1. 正常登录 CEOACC，打开「所有产品」商品列表，确保页面商品行已加载。
  2. 按 F12 → Console（控制台），将下面的采集代码粘贴进去并按 Enter。只读取当前页面显示的商品名称、价格和「剩余」数字，不读取账号详情、Cookie 或密码。
  3. 浏览器会下载当天的 ceoacc-stock-YYYY-MM-DD.csv。回到本面板导入该 CSV。
  4. 明天重复一次。第二份快照导入后自动生成库存减少 TOP 50。

注意：当前采集器根据商品列表 HTML 表格行中可见的「剩余: 数字」识别库存。若网站改版或页面未加载完整，可能识别不到所有商品。请先试采一次并检查 CSV。

复制后粘贴到 CEOACC 页面自己的 Console 中执行。
