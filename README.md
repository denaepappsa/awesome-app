# CEOACC 每日库存 TOP 50（简易方案）

## 使用方式
1. 每天从 CEOACC 页面或卖家后台手动导出/整理商品库存 CSV。
2. 打开 `index.html`，点击“导入今日库存 CSV”。
3. 第一天导入只建立基准；第二天及以后自动按库存减少量计算 TOP 50。
4. 可导出排名 CSV。

## CSV 必需格式
```csv
product_id,name,stock,captured_at
SKU001,商品A,120,2026-11-02
SKU002,商品B,50,2026-11-02
```
一个 CSV 文件只包含一个日期。商品 ID 必须跨日期保持稳定。

## 数据说明
估算减少量 = 上一快照库存 - 当前快照库存，仅展示大于 0 的结果。它不是已确认订单销量；补货、取消订单、规格调整等可能影响库存变化。数据保存在使用者当前浏览器的 localStorage，不会自动同步到其他设备。

## 为什么采用手动方案
之前自动访问 CEOACC 遇到访问拦截。此版本不再自动抓取网站、不绕过访问控制。只有在网站提供可正常导出的库存数据后，才考虑接入官方 API 或获授权的数据源。
