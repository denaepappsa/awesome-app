# CEOACC 每日库存 TOP 50

这是一个轻量级库存快照比较面板，针对 CEOACC 商品页制作。

## 当前功能
- 从 CEOACC 已打开的商品列表页面提取可见商品行、名称、库存数字和价格，并下载当天 CSV。
- 将每日 CSV 导入面板，数据保存在本机浏览器。
- 对比最近两个日期的库存快照，按库存净减少量生成 TOP 50。
- 支持搜索、CSV 模板和 TOP 50 导出。

## 使用
1. 打开部署后的 `index.html`。
2. 面板中点击“复制采集代码”。
3. 在已正常打开的 CEOACC 商品列表页打开 Chrome DevTools -> Console，将采集代码粘贴并运行。
4. 代码只读取当前页面 DOM 中可见的商品名称、库存和价格，不访问 Cookie、Token、密码，不调用隐藏接口。
5. 下载 CSV 后回到面板导入。
6. 次日重复采集并导入，系统即可对比并生成排名。

## 识别规则和限制
采集器目前尝试从商品列表的 `tr` 行中识别“剩余: 数字”或“库存: 数字”，并从同一行提取名称和价格。这是基于当前用户截图推断的初版规则，尚未在真实 CEOACC 页面完成端到端验证；如果网站布局不是标准表格或某些商品使用动态组件，可能漏读或误读，需要根据实际导出 CSV 调整。

库存减少量只是库存变化估算，不等于已确认订单销量。补货、取消订单、规格变化、后台调整等都会影响差值。商品以提取出的名称生成匹配 ID，同名商品可能需要进一步区分。

## 自动化状态
目前尚未设置云端每日定时任务，也没有在服务器保存历史快照。用户需要每天手动在 CEOACC 页面执行一次采集并导入 CSV。原因是网站此前在云端访问环境返回 403/1010；项目不尝试绕过访问控制或 Cloudflare 防护。

## 部署
可将仓库作为静态网站部署（例如 GitHub Pages）。部署完成前，仓库文件本身不是一个已上线的网站。
